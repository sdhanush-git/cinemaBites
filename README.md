# Cinema Bites

A responsive movie discovery web application built with React.js that allows users to browse trending movies, search for movie titles, and view detailed information.

## Features

- Browse trending movies
- Search movies
- Movie details page
- Responsive UI
- React Router navigation

## Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite
- REST API

## Live Demo

https://cinemabites.netlify.app

## Installation

git clone https://github.com/sdhanush-git/cinema-bites.git

cd cinema-bites

npm install

npm run dev
